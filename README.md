# Justin Olivo | Applied AI Engineer Portfolio

Personal portfolio site for Justin Olivo, an applied AI engineer building agentic systems that ship as working apps: retrieval over trusted sources, multi-model routing, and agent workflows. It is aimed at AI teams, startups, and freelance clients.

## What's on the site

- Approach: right model for each task, retrieval over guessing, domain judgment from nine years in healthcare
- Case study: CardioBot, a multi-model RAG assistant ([live demo](https://cardiodoc.streamlit.app), [code](https://github.com/JustinOlivo52/cardiobot))
- Capabilities, projects in progress, freelance services, experience, and contact options

CardioBot is a portfolio project built for demonstration. It is not for clinical use.

## About this repo

A single static page: plain HTML and CSS with a few lines of JavaScript for the copy-email button. No build step and no dependencies. Fonts load from Google Fonts.

```
index.html   the whole site
README.md    this file
```

A sibling site aimed at healthtech roles lives in its own repo.
